## 1. 施工前的代码理解（P1 相关事实）

1. **服务端现状**：`owo-agent serve` 在 `commands/serve.rs` 里
   `TcpListener::bind` → 打印一行 `core_ready`（含 pid/port/api_version/build_id）
   → `axum::serve`。端口只经 stdout 暴露；`server.pid` 只有 pid、**没有端口**。
2. **发现的缺口**：CLI/TUI/桌面无法发现"已运行 Daemon 的端口"，因此 F-01 里
   "多入口各自建 Agent / 抢数据库"根因之一就是**没有共享发现通道**。
   指南 §2.3 明确要求原子替换的 `runtime/daemon.json`。
3. **认证**：`<data_root>/auth/token` 每次启动换发；`GET /auth/token` 为公开引导
   （发布桌面壳用配对证明/实例身份收紧）。token **不得**写进发现文件。
4. **需要的路由**（已存在，客户端直接消费）：`GET /health`（公开）、
   `GET /sessions`、`POST /session`、`GET /session/{id}`、
   `POST /session/{id}/turn`（SSE，`type=token_delta/final/...`）、
   `POST /session/{id}/abort`、`POST /session/{id}/permission/{request_id}`。
5. **依赖边界**（指南 §3.1/§3.2）：`clients → owo-agent-client → owo-agent-protocol`；
   客户端禁止依赖 core/server/sqlite/mcp/perception/executor/policy。

## 2. 施工记录（增量 1）

### 2.1 `owo-agent-protocol`：新增发现契约

- 新增 `pub struct DaemonDescriptor { pid, port, instance_id, api_version, build_id, started_at, data_root }`。
  发现文件与客户端/服务端共享同一 DTO，避免两侧各自定义漂移。

### 2.2 `owo-agent-server`：新增 `discovery` 模块（写入端）

文件 `crates/owo-agent-server/src/discovery.rs`：
- `descriptor_path` / `write_descriptor`（tmp → rename 原子替换）/ `DiscoveryFile`（Drop 清理）；
- `now_rfc3339`、`mask_data_root`（`<目录名>-<sha256 前 12 位>`，**不写绝对路径**）；
- `read_descriptor`、`process_alive`、`recover_stale`（陈旧 pid 清理）。
- 4 条单元测试：round-trip + Drop 清理、缺失文件不 panic、脱敏不含绝对路径、死 pid 判陈旧。

### 2.3 `owo-agent-cli`：`serve` 写发现文件

- 端口绑定、打印 `core_ready` 后写入 `<data_root>/runtime/daemon.json`；
  写入失败仅告警（客户端退化为"未发现"，安全）。
- 优雅关闭路径显式删除发现文件（`process::exit` 不跑 Drop）。
- `Cargo.toml` 增加 `owo-agent-protocol`（构造描述符）。

### 2.4 新增 `crates/owo-agent-client`（唯一共享客户端）

```
src/lib.rs          门面 + connect(data_root, expected_api_version)
src/error.rs        ClientError（NotFound/Discovery/Auth/Transport/Status/Protocol/ApiVersionMismatch）
src/discovery.rs    DaemonDiscovery（读+pid 存活+API 版本校验）、resolve_data_root
src/auth.rs         read_token / bootstrap_token（配对/实例头）
src/http.rs         AgentClient（bearer 认证、JSON 往返、SSE 原始流、结构化错误）
src/sse.rs          SseBuffer（字节缓冲，跨 chunk UTF-8 安全）+ TurnStream
src/sessions.rs     create/list/get
src/turns.rs        open_turn（SSE）/ cancel_turn
src/approvals.rs    respond_permission
src/diagnostics.rs  health / server_status
examples/discover.rs 最小可运行发现示例
```

- `Cargo.toml` 依赖仅 `owo-agent-protocol/serde/serde_json/tokio/reqwest/thiserror`。
- 工作区 `members` 与 `workspace.dependencies` 已登记。

### 2.5 契约测试

- `tests/dependency_guard_tests.rs`：逐行解析 Cargo.toml，断言生产依赖**不含**
  core/server/mcp/perception/executor/policy/sqlite 等（§3.2 守卫），且必须含 protocol。
- `tests/client_contract_tests.rs`：SSE 半包/UTF-8 跨 chunk、非 data 行、发现文件
  正常/陈旧/缺失，以及对**假 Daemon**（原生 tokio TCP，不依赖 server）的
  health/session/turn-SSE/abort 端到端往返。

### 2.6 `mk-smoke.ps1`：新增发现文件运行态门

- 新增检查 `daemon.discovery_file`：发现文件必须存在，且 `pid/port/api_version`
  与 `core_ready` 自报值一致。

### 2.7 CLI `support`：单实例启动协议（增量 2）

- 新增 `ensure_daemon_client(data_root, workspace)`：
  先 `owo-agent_client::connect`（有则**复用**）；`NotFound/Discovery` → `spawn_daemon`；
  `ApiVersionMismatch` → 明确报错（增量 6：拒绝静默连旧实例）。
- `spawn_daemon`：以当前 exe 启动 `serve --port 0 --output jsonl --workspace …`，
  `OWO_AGENT_DATA` 指向同一数据根，stdout/stderr 重定向到 `<data>/logs/daemon-*.log`，
  Windows 用 `DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP | CREATE_NO_WINDOW` 分离。
- 客户端新增 `request_shutdown(confirm)`；`daemon status/stop` 经 discovery + 客户端。

### 2.8 CLI `turn`：改走共享客户端（增量 3）

- `commands/turn.rs` 重写：**删除** `Agent::new` / `SqliteSessionStore::open` /
  `connect_mcp_clients` / `build_agent`；改为
  `ensure_daemon_client` → `create_session_with_model` → `open_turn`（SSE）→ 事件渲染 →
  `session_diff` → 结束。
- 审批：trusted 自动允许；human 交互 `y/s/N`（一次/会话/拒绝）；jsonl 默认拒绝（不阻塞编排）。
- Ctrl+C → 客户端 `cancel_turn`（贯穿 Daemon abort）。
- `EventPrinter`/`print_event` 迁到 `ui_output.rs`（repl 复用），使 `turn.rs` 可完全脱离 core。
- JSONL 协议保持 `{"type":"turn_event","event":<SseEvent>}` / `turn_result` / `error` 形状。
- 静态守卫 `tests/turn_path_guard_tests.rs`：扫描 `turn.rs`/`daemon.rs`（先剥注释），
  禁止 `Agent::new`/`SqliteSessionStore`/`connect_mcp_clients`/`build_agent`/`owo_agent_core` 等。

### 2.9 跨客户端一致性验收（增量 5）

- 新增 `scripts/verify-cross-client.ps1`（自清理，避免孤儿 Daemon）：
  1. 全新数据根下 CLI `turn` **自动拉起** Daemon（并清理）；
  2. HTTP 客户端建会话 A；CLI `turn` **复用同一 Daemon** 建会话 B；
  3. 同一 `/sessions` 同时看到 A 与 B；
  4. `owo-agent-client` 示例看到同一批会话；
  5. `daemon status` 的 pid/port 与 core_ready 一致；`daemon stop` 优雅停止；
  6. `-RealTurn` 时经 CLI 共享客户端跑真实模型并断言 `turn_result.final_text`。

### 2.10 顺带修复

- `crates/owo-agent-workswarm/src/team_benefit.rs`：doc 列表与段落之间补空行，
  修复新版 clippy `doc list item without indentation`（否则 `clippy -D warnings` 全局被挡）。

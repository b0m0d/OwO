# 输入法直接调用 Agent：使用与验收

更新：2026-10-21。分支 feat/ime-agent-access，基于 agent-frame @ 98324302。master 和 agent-frame 继续作为主仓库两个主要分支。

## 使用
在 Agent Desktop「设置 → 输入法」选择调用模式、工作目录和工具范围，保存后立即生效。可选跟随 Agent、只读、自定义文件/命令/联网维度、关闭任务调用。原有 Agent 拒绝规则和审批继续生效；改范围会撤销并中止活动输入法任务。

在 OwO 输入法进入 Agent 模式，再点桌面「连接输入法…」，亲自核对本机配对窗口。配对绑定当前连接器进程与程序摘要，有效一小时，重启后重新连接。

提交普通任务并选择确认候选后，进入现有 Agent 持久会话。工具审批候选唤起现有 Agent Desktop 对应会话。完成后可查看任务、选择插入回复，不自动上屏。输入位置变化时任务在工作台继续；明确取消才中止回合。改写、翻译等仍走原有无工具表达路径。

## 实现
- 新增 /ime/tasks、/settings/ime；同步 OpenAPI 与 TS 类型。
- 任务来源有独立 audience/scope/key ID/HMAC purpose，不能复用表达来源凭证。来源认证本身不授权执行。
- 工作目录由桌面配置，网关任务不能指定目录。请求级限制叠加实时宿主策略，执行前再次检查，嵌套调用保留限制。
- IME 来源随会话和分叉保留，SQLite v11。持久身份去重避免再次执行，普通桌面恢复仍受当前范围约束。
- 自定义只开放实际执行的维度、工作目录和工具。拒绝旧 PermissionSpec 的描述性 scopes 和 filesystem=custom。自定义的命令/联网审批要求不会被宽松宿主档位覆盖。
- 只读、自定义或指定工具时暂停用户命令钩子。跟随全部 Agent 能力时保留原钩子。
- 复用当前已登记的工具和扩展。现有工作流、团队、浏览器、桌面能力的模型调用面仍取决于原产品注册与配置，没有另建 Agent、工具表或 MCP 宿主。
- IME 和网关独立构建，IPC v3/v4形状不变；已安装1.3.2连接器可以复用。未替换或注册TSF DLL。
- Electron打包前置加入网关构建、摘要清单和资源。本次未生成/发布安装包。

## 配对失败修复

首次配对后网关结束、真实请求返回agent_disconnected。核查发现本机确认窗口复用了60秒内部事务凭证，用户阅读窗口超过一分钟后确认会失败，但窗口未提示超时。现在在实际Yes动作后重新核对完整内核身份，再开启短时事务；配对仍绑定同一进程实例与程序摘要，不放宽内部事务过期和重放检查。

同时修复无控制台后台启动时信号注册失败被误当作退出的问题：监听失败不再发送停止信号，保持关闭通道有效，由Desktop管理进程退出。补全桌面失败状态和固定原因提示，保留已有具体错误，不向渲染层转发原始网关输出。

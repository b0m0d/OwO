### 本批发现并修复的文档外回归（门禁纪律的直接收益）

1. `mcp_health::snapshot_...`：默认阈值 3 下第 3 个连续失败恰触发开路，旧测试
   期望"3 失败后仍 0 次熔断"与实现矛盾 → 重写为 Degraded→恰一次开路→
   开路窗口内不重复计次的完整状态机断言。
2. `observe::memory_store_round_trip_and_clear`：fixture 固定 `2026-08-12`
   落在 30 天保留期外，随日历必然失败（时间炸弹）→ 新鲜时间戳 +
   新增 `memory_store_prunes_expired_observations` 显式冻结保留期契约；
   `memory_prune_caps_entries_and_drops_expired` 同步修（否则退化为恒真）。
3. `agent::model_phase_timing_...`：first_token_ms 用 0 作未触发哨兵，吞掉
   合法的 0ms 首 token → 改 `u64::MAX` 哨兵（观测正确性修复，非仅测试）。
4. `memory_graph_tests`：fixture 绝对日期同因过期 → 进程级相对锚点
   （跨 UTC 午夜一致；query 用 Z 后缀避免 `+` 在 www-form 解码为空格）。
5. 构建链物理前提：`target/` 被 68.1GB debug 产物填满（LNK1318 PDB LIMIT）；
   ORT 预构建从可删除的 `target/sherpa-onnx-prebuilt` 迁至稳定缓存
   `%LOCALAPPDATA%\OwO\Agent\runtime\1.13.5`（init-dev-env 既有优先级路径，
   版本 + 归档 sha256 校验不变），删除 target/debug 释放 64.6GB。
   注：这是**依赖不再随 target 一起毁灭**的迁移，不等于 R2"新终端零手工
   变量"完成——R2 仍需把调用方统一收口并验证空环境。

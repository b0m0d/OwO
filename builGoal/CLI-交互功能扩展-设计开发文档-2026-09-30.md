# CLI 交互功能扩展 — 设计开发文档（2026-09-30）

> 目标：把 OwO Agent CLI 的交互能力对齐 Codex CLI，并补上 Markdown 渲染与上下文压缩。
> 本文件随做随更；代码改动以「契约测试 + `cargo fmt`/`clippy` 干净」为准。

## 1. 背景

用户实测反馈两点：

1. **没有 Markdown 渲染**：模型输出 `**加粗**`、反引号、`# 标题` 在终端里是裸符号。
2. **缺少 `/compact` 等命令**：Codex 有的斜杠命令需要补齐。

现状：REPL 有两条路径——默认走 **Daemon 客户端**（`repl_daemon.rs`），`--local` 走本地
（`repl.rs`）。两条路径的命令面需要保持等价。

## 3. Markdown 渲染设计

- 新增 `crates/owo-agent-cli/src/markdown.rs`：轻量、**按行**渲染，适配流式 token。
  - `MarkdownStream::push(delta)`：累积到换行，渲染整行后输出；围栏 ``` 原样缩进展示。
  - `render_block_line`：标题（`#`..`######`）、引用（`>`）、无序列表（`- * +`）、分隔线。
  - `render_inline`：`` `code` ``、`**bold**`/`__bold__`、`*italic*`/`_italic_`、
    `~~strike~~`、`[text](url)`。
- 接入点（仅 human 模式）：
  - 本地 REPL：`ui_output::EventPrinter`（`TokenDelta` 喂入、`Final`/工具事件前 flush）。
  - Daemon REPL：`repl_daemon.rs` 流式循环。
  - `turn` 命令：human 模式流式循环；`plain`/`jsonl` **不渲染**（保持机器可解析契约）。
- 不追求完整 CommonMark；嵌套/表格等复杂结构按原样输出。

## 4. `/compact` 设计

Codex 的 `/compact` 是「立即把历史压缩成摘要」。分三层实现：

1. **core**：`Agent::maybe_compact` 增加 `force: bool`；新增公开
   `Agent::compact_session(&self, &mut Session) -> Result<Option<String>, AgentError>`，
   不依赖 token 预算即可压缩（仍受 `compaction_enabled` 约束）。
2. **server**：新增 `POST /session/{id}/compact` → `session_api::compact_session`，
   返回 `{compacted, summary, tokens_before, tokens_after, messages}`；同步
   `tests/route_contract_tests.rs`。
3. **CLI**：
   - Daemon：先 `GET /session/{id}/context` 显示占用，再 `POST .../compact` 触发；
   - Local：本地计算 `estimate_tokens` 并调用 `agent.compact_session`，保存会话。

## 5. 其余命令设计

- `/review [提示]`：发起一次「审查本次改动」的回合（默认提示：审查工作区 diff，指出缺陷与风险）。
- `/mention <路径>`：解析路径、打印相对路径与大小/行数，供用户引用；无参时给用法。
- `/history [n]`：打印最近 n 条输入历史（本地读 history 文件；Daemon 读同一路径）。
- `/editor`：调用 `$VISUAL`/`$EDITOR` 打开临时文件，读回多行作为一次输入。
- `/login` / `/logout`：env 凭据诊断（`OPENAI_API_KEY` 是否存在/长度、端点、模型）；
  `/logout` 仅提示「凭据来自环境变量，请用 `setx`/系统设置移除」——**不回显密钥**。
- `/debug`：输出工作区、数据目录、模型、权限档位、MCP/Skills 计数、会话 id、trace 目录。

## 8. 已知限制 / 后续

- Markdown 渲染仅覆盖常见子集（标题/引用/列表/行内代码/粗斜体/删除线/链接/围栏）；表格、
  嵌套列表、HTML 按原样输出。
- `/compact` 对「历史不足」的会话不产出摘要（`head_end < keep_recent`），提示为「未压缩」。
- Daemon 路径的 `/editor`、`/mention`、`/history`、`/login`、`/logout`、`/debug` 均为本地行为，
  不经服务端；`/compact`、`/review` 走服务端。
- 尚未实现（不适用/低优先）：`/theme`、`/vim`、`/ps`、`/feedback`。

## 2. M4.2 真实缺口与实施（本会话主交付）

**根因**：`Session.model` / `SubagentRunner.model` 历史上只是**展示值**——
`OpenAiCompatibleProvider::request_body` 永远取 `OPENAI_MODEL` env/启动配置，
"会话级模型选择"整条链路是断的（指南验收 1"指定模型出现在请求体"必然失败）。

**实施**（保持现树架构，不复活指南旧 config.rs 设计）：

1. **wire 层请求级覆盖**：`ModelProvider` 新增默认方法
   `complete_with_model` / `complete_stream_with_model`（37 个既有测试桩零改动兼容）；
   `OpenAiCompatibleProvider` 实现进请求体；`ResilientProvider` 主链+fallback 全链透传。
2. **哨兵与归一**：`MODEL_DEFAULT_SENTINEL="default"`；`effective_model` 对
   空串/空白/哨兵一律回退解析链（**哨兵绝不进请求体**）；`Session::normalize_model_override`
   保证哨兵**不落库**；create/subagent 两个 HTTP 边界同语义归一（双层防线）。
3. **档位路由**：`ModelTier{Main,Fast,Vision}` + `resolve_tier_model`
   （`OWO_MODEL_FAST`；`OWO_MODEL_VISION` → 兼容视觉通道既有 `OWO_VISION_MODEL`）。
   接线点：`maybe_compact`（历史压缩=fast 档）、`subagent_api`（显式 > fast > 自动三级优先）。
4. **会话持久化**：`Session.model_override: Option<String>`（serde default，旧 JSON
   兼容）；SQLite 注册迁移 **v2**（`model_override TEXT`，旧库旧行 NULL 兼容，
   实测迁移幂等 + 用户真实 index.db 首开无损）；fork 继承覆盖。
5. **HTTP 面**：`POST /session` 的 `model` 字段语义升级为真实路由（GET 增
   `model_override` 暴露路由真相）；**新路由 `POST /session/{id}/model`** 设置/清除覆盖
   （lib.rs router+openapi_spec+`clients/ts/openapi.json` 快照三处同步；
   route_contract 双向路径集一致断言绿；mutation 事件矩阵 +1 行）。
6. **子代理运行时修正**（连带发现的真实回归面）：agent.rs 两处
   `SubagentRunner.model` 原样传 `session.model`（展示值）→ 改传
   `model_override`（父固定则子同模型、父自动则子走链——修复热切换下钉死旧展示值的隐患）。
7. **视觉凭据回落**：`VisionConfig.api_key` 未配 `OWO_VISION_API_KEY` 时复用
   `OPENAI_API_KEY`（指南"复用现有凭据"意图；红线不破——仍只经环境变量）。

## 4. 发现与后续（不阻塞本收口）

1. **契约层 vs 小模型**：`glm-4-flash` 跑子代理时 `WorkerOutputV1` 结构化输出偶发
   不合规（evidence 字段给字符串、定向修复一次仍失败 → `output_contract_invalid`，
   live 实测命中一例）。属模型能力档问题：fast 档选型应偏向契约服从性好的型号，
   或后续给契约修复 prompt 增补字段级示例（三路契约域，本会话未越界改）。
2. **同回合子代理并行**：工具级并发仅覆盖"宿主验证只读工具"（
   `call_is_concurrent_eligible`），`subagent`/`explore` 不在并发资格内——多 Agent
   并行现由 WorkSwarm（max_parallel=4）承担；若未来放开需先解决审批链交错。
3. **UI 模型选择控件**：HTTP 面已具备（create/`/model` 路由 + GET 暴露
   `model_override`），桌面 web 的模型下拉接线属 R3/四路认领域，本会话未动。
4. **指南文件本身**：其基线已漂移，建议后续以本记录+现树代码为准归档退役，或标注
   "快照引用失效"批注（本会话不改他人文档）。

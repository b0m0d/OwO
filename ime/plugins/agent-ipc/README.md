# OwO Agent IPC 连接器

当前插件版本：`1.3.0`

这是 OwO 维护的高权限本机 IPC 桥接插件。它不会执行 Agent 返回的自然语言，职责仅限于：
收集用户明确确认的请求、按用户配置保留带应用标识的有限局部上下文、脱敏、连接本机第三方 Agent、展示结构化结果并返回用户选择。

`1.3.0` 默认使用 Agent 协议 v3，并兼容读取 v2。v3 支持任务意图、槽位、原拼音区间双向映射和只传输槽位补丁的增量候选；已锁定槽位不会被候选静默覆盖。它可在切换应用或输入位置后继续携带内存中的近期
OwO 上屏片段，并为每段附加不透明上下文 ID、应用和焦点控件信息。升级会触发重新授权。
v3 进一步提供结构化拼音输入、请求幂等标识、能力声明、上下文相关度和隐私状态、
结构化命令风险以及可取消进度/错误信息。

启用前必须在设置中心阅读权限与隐私告知并明确同意。完整使用与第三方接入规范见：

- `docs/plugins/agent-ipc-privacy.md`
- `docs/plugins/agent-ipc-integration.md`
- `docs/plugins/agent-ipc-mock.md`

开发构建目标为 `owo_agent_ipc_plugin`。发行打包时必须把该目标复制为
`bin/owo-agent-ipc-plugin.exe`，不要从源码目录直接运行。

使用小写 `v` 作为预编辑串首字符进入 Agent 模式。`v` 与后续内容以 `v +` 分隔显示，
不参与拼音解析。候选完整消耗请求时可自动发送；Enter 或 Space 可显式确认。删除已选
候选时先恢复其原拼音，只有明确删除开头的 `v` 才退出尚未结束的 Agent 会话。

该连接器不包含模型或 Agent 工具运行时，也不会执行返回的自然语言。第三方 Agent
必须按照接入规范提供本机命名管道服务，并在自身可信界面确认高风险系统操作。


配对认证（1.3.2 开发版）：网关以显式配对参数启动并由用户确认后，会给出当前用户DPAPI保护的`.owokey`文件路径。将路径填入`pairing_credential_file`，会强制启用认证；凭据缺失、损坏或权限不符合要求时拒绝发送，取消请求也使用同一认证路径。不得将模型API key或明文配对密钥写入设置。旧第三方普通JSON模式仅在未启用配对时保留，不能当作认证网关使用。

目前为本地开发接线，未取得真实用户配对/安装验收；程序SHA256由操作者从已核对构建收据提供，不等同签名安装器证明。网关重启后内存授权失效，需要重新确认配对；凭据文件残留不会自动恢复授权。

新版网关命令入口必须使用配对参数并完成确认；不带参数会拒绝启动，不再默认开放普通JSON管道。连接器的未配对兼容选项仅供独立第三方/mock端点使用，不能连接新版认证网关。

# OwO 大创实施方案：会学习的输入法——授权语料学习、输入预测与语气模仿

> 更新：2026-10-22。按用户初衷修订：核心是给输入法加上**经用户授权的学习记忆**，用学到的语料更好地**预测输入**和**模仿用户的回复语气**；Agent 协同作为延伸。
> 源码基线：master@594f9732、agent-frame@98324302，以及 feat/ime-agent-access 中尚未提交的实现。本文只是方案，所列新功能均未实现。

## 0. 一句话

**用户授权后，输入法在本机记住你平时怎么打字、怎么说话，帮你更快打出想说的词句，并能按你的语气起草回复；需要做事时再交给已有 Agent。**

建议项目名称：**OwO——基于授权语料持续学习的个性化智能输入法**。

## 1. 要做成什么

| 能力 | 用户感受 | 定位 |
| --- | --- | --- |
| 学习记忆 | 授权后，输入法记住自己常用的词、短语、句式和不同场合的说话方式；可查看、暂停、删除 | 核心，必做 |
| 输入预测 | 打完一个词，候选里出现自己常接的下一个词/短语；停顿时可给出整句续写 | 核心，必做 |
| 语气模仿 | 选中对方消息或写个开头，生成"像自己说的"回复，预览后上屏 | 核心，必做 |
| Agent 协同 | 需要查资料、整理项目进展时，从输入法交给已有 Agent，结果回到输入框 | 延伸，已有底座，按余力做 |

"持续学习"指本地语料库、词组统计、风格档案随使用不断更新，不是每次按键训练大模型。

### 1.1 演示流程

1. 用户在设置中开启学习，选择允许学习的应用（如微信、Word），密码框等敏感输入自动不学。
2. 正常用一段时间后，输入"老师我们这周"，候选栏直接出现自己常写的"把……跑通了"。这部分完全在本地完成，不调用模型。
3. 收到同学消息"明天组会几点？"，选中后点"按我的语气回复"，得到 2–3 条风格像自己的回复，选一条上屏。
4. 用户在预览里改了一处措辞，这次修改作为一条反馈，影响以后的生成。
5. 打开"我的语料"，能看到学到了什么，可以删掉某条、清空某个应用，或整体暂停。
6. （延伸）在写项目汇报时选"让 Agent 查一下项目待办"，Agent 读取指定文件后，把结果用自己的语气整理好放回输入框。

### 2.2 尚未完成

按优先级排列。前五项是项目核心。

| 编号 | 工作 | 完成标准 |
| --- | --- | --- |
| L1 | 学习授权与本地语料库 | 设置中可开关、按应用允许/排除；敏感字段自动跳过；只记录本人上屏的文字，本地加密存储；可查看、删除、清空、暂停 |
| L2 | 本地词组/短语统计与下一词联想 | 从语料中统计常用搭配，候选栏给出下一个词或短语；纯本地，不增加明显打字延迟 |
| L3 | 风格档案 | 按场景（聊天、正式汇报等）提取句长、标点、常用口头语、正式程度；用户可查看和修改 |
| L4 | 按我的语气回复/续写 | 选中消息或写开头，检索自己相似场景的例句交给模型，生成 2–3 条候选，预览后上屏；不编造事实 |
| L5 | 反馈学习 | 采纳、在预览中修改、拒绝、撤销分别记录，影响后续排序和生成；可回滚错误学习 |
| L6 | 学习效果评测 | 用留出的本人文本测联想命中率、按键节省；对语气生成做盲选对比（见第 6 节） |
| A1 | 修复桌宠确认后提交，完成实际 TSF 候选与回写验收 | 真实 UI 发起、真实候选选择、结果取用分别通过 |
| A2 | 输入法到 Agent 的场景化建议（汇报、项目问题） | 少量固定动作、预览后执行，不扩大已有权限 |
| A3 | 结果待取与切换窗口后重新挂接 | 不重复执行，旧位置失效时让用户重选 |
| R1 | 可安装原型与演示 | 有支持应用清单、版本号和真实演示 |

还没有的东西：句子级语料学习、下一词联想、风格档案、语气生成、反馈闭环、学习设置界面，以及任何个性化效果数据。现有实现中有一部分还没提交、推送，也没有发布安装包。

## 3. 学习记忆怎么做

### 3.1 学什么、不学什么

| 来源 | 处理 |
| --- | --- |
| 授权应用中，经输入法上屏的本人文字 | 主要语料；按应用和场景标记后存入本地语料库 |
| 用户主动导入的本人文字（如以前写的汇报） | 补充语料，冷启动时用 |
| 在语气生成预览中的修改 | 强反馈：说明用户想要的说法 |
| 拒绝、撤销 | 降低相应说法的权重；原因不明时只记曝光，不改风格 |
| 粘贴的内容、对方的消息、AI 原文直接上屏 | 不当作本人语料 |
| 密码、验证码、支付等敏感字段；未授权应用 | 不记录 |

输入法只能看到经它上屏的文字，所以"学用户输入"在技术上是可归因的：上屏的就是本人打的。粘贴和其他输入法打的字不经过本输入法，天然不会学到。

### 3.2 存储分层

1. **词频层（已有）**：哪个候选更常被选。
2. **搭配层（新增）**：本地 n-gram 统计（如"跑通"后面常接"了"），用于下一词联想；数据小、查询快，打字时可同步使用。
3. **语料层（新增）**：按应用/场景保存的句子，设条数和保留期上限，用于检索例句。
4. **风格档案（新增）**：从语料统计出的可解释特征，加上用户手写的偏好（"简短、少用感叹号"）。

全部存在本机用户目录。只有使用语气生成时，才把少量相关例句和当前消息发给模型；发送前设置中写明发送范围，用户可选择只用本地功能。

### 3.3 预测与生成

- **下一词/短语联想**：本地搭配统计加已有词频，排在普通候选之后或单独显示；不调用模型，不阻塞按键。
- **整句续写**：用户停顿或手动触发后异步请求模型；继续打字时丢弃过期结果。
- **语气回复**：检索同场景的少量本人例句，加上风格档案和当前消息，生成 2–3 条；事实（时间、人名、完成事项）只能来自用户给出的内容，不从语料里编造。
- 模型不可用时，普通输入和本地联想照常工作。

先用规则、统计和例句检索做出可解释的版本，效果不够时再考虑本地小模型或微调。联邦学习、差分隐私不作为首版交付。

## 4. 与 Agent 的关系

Agent 部分已有可用底座（2.1 节），本项目不再新造执行体系，只做两件事：

1. 先修好已有入口（A1），保证"输入法 → Agent → 结果回到输入框"能现场演示。
2. 把学习成果接到 Agent 输出上：Agent 产出的汇报和回复可以套用用户的风格档案。

"预测下一步该交给 Agent 做什么"（A2）是加分项，核心做完后再做，只做少量固定场景。猜到意图不代表获得执行授权，执行仍走已有的权限和审批。

## 5. Desktop 设置

沿用「设置 → 输入法」，新增：

| 区域 | 选项 |
| --- | --- |
| 学习记忆 | 总开关；允许/排除的应用；暂停学习；保留期 |
| 我的语料 | 浏览、搜索、删除单条，按应用清空，全部清除，导入本人文本 |
| 我的风格 | 查看档案，手写偏好，按场景开关 |
| 预测与生成 | 下一词联想开关；整句续写开关；语气回复是否允许调用云端模型 |
| Agent 调用 | 沿用现有权限设置 |

删除后清理本地语料、统计和索引；已发给云端模型的内容无法撤回，界面要写清楚。

## 6. 研究、志愿者和大创是什么关系

大创（大学生创新创业训练计划）结题时，一般需要说明做了什么、解决了什么问题、效果如何。能装、能演示的原型证明"做出来了"；要说明"学习真的有用"，还需要数据。这就是研究部分的作用：**它是给学习功能出具效果证据，不是另一项独立任务。**

为什么需要别人参与：学习效果因人而异，只拿开发者自己的数据，说服力有限；语气像不像，也只有本人能判断。

可以按条件选择规模：

| 规模 | 做法 | 能说明什么 |
| --- | --- | --- |
| 最小 | 团队成员 3–5 人，各自用一段时间，用自己留出的文本测试 | 功能可用，有初步效果，属于探索性结果 |
| 推荐 | 再找 6–10 名同学，使用 1–2 周 | 有一定代表性，可以写进结题报告 |
| 扩展 | 20 人左右，有对照组 | 可以支撑论文 |

测什么（都和学习功能直接相关）：

1. **联想命中率与按键节省**：用每人最后一段时间的文本作测试集，前面的作学习语料，比较"开启学习"和"不学习"时下一词联想的命中率、平均少按的键数。可以离线计算，不打扰参与者。
2. **语气像不像**：对同一条消息，分别用"通用生成"和"按我的语气生成"各出一条，打乱后让本人盲选哪条更像自己会说的。
3. **越用越好吗**：比较学习 3 天、7 天、14 天后的命中率变化。
4. **不能变慢**：普通打字的候选延迟与关闭学习时对比。

涉及他人的输入语料，必须做到：

- 书面知情同意，写清楚收集什么、存在哪、存多久、怎么退出；
- 数据留在参与者本机，研究只回收统计结果（命中率、选择结果），不回收原文；
- 参与者随时可以退出并删除数据；
- 报告和公开材料不出现私人原文。

## 7. 风险

| 风险 | 处理 |
| --- | --- |
| 隐私顾虑 | 默认关闭；按应用授权；本地存储；敏感字段不学；可查看、删除 |
| 学到错误或一次性表达 | 计数上限、衰减（沿用已有词频机制）、反馈回滚 |
| 联想打扰打字 | 本地计算、不抢普通首选、可关闭 |
| 语气模仿编造事实 | 事实只取自用户输入；风格例句不当作事实 |
| 宿主应用不兼容 | 先验收少数常用应用，列出支持清单 |
| 效果不明显 | 如实报告；分析原因（语料量、场景） |
| 范围失控 | 先做 L1–L5，Agent 延伸项按余力取舍 |

## 8. 申报用概述

### 8.1 概述草稿

现有输入法的个性化大多停留在词频调整，难以学习用户的表达习惯和说话语气。本项目基于自研 Windows 中文输入法和本地 Agent 框架，研究经用户授权的输入语料持续学习方法：在本机分层保存词频、词语搭配、分场景语料和风格档案，用于下一词联想、整句续写和按用户语气生成回复，并通过用户的采纳、修改和撤销持续改进。系统在需要时可将任务交给已有 Agent 执行，结果按用户风格回到输入框。项目已完成输入法核心、本地词频学习，以及输入法调用真实 Agent 的工具链路；语料学习、联想预测与语气生成为本期主要工作。项目将通过用户参与的离线与盲选评测，验证学习对输入效率和表达贴合度的提升。

### 8.2 创新点

1. **可授权、可查看、可删除的分层学习记忆**：区分词频、搭配、语料和风格，数据在本地，用户能看到、改掉学到的内容。
2. **输入场景下的语气模仿**：在输入法里直接按本人风格生成回复，风格（怎么说）和事实（说什么）分开处理，避免编造。
3. **输入法与 Agent 协同**：输入法既能预测词句，也能把任务交给 Agent，产出再按个人风格回到原输入框，执行权限受已有策略约束。

### 8.3 成果

1. 可安装的 Windows 原型和支持应用清单。
2. 学习设置、语料管理和风格档案界面。
3. 下一词联想、整句续写、语气回复功能。
4. 学习效果评测报告（命中率、按键节省、盲选结果、延迟）。
5. 演示视频；软著、论文视成果再定。
